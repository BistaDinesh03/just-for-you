## What is it?

Just For You lets you build a personal, interactive website for someone you care about. It could be a proposal, a love letter, a birthday message, an anniversary, or just something sincere.

No photos required. No coding needed. Just your words.

---

## Features

- Interactive story experience
- Personal messages and memories
- Works with or without photos
- Mobile-first design
- Smooth cinematic transitions
- Customizable from one config file
- Optional response notifications
- Free to deploy

---

## Make it Yours

```

Fork → Edit config.js → Add your content → Deploy → Send
text

```

Everything personal lives in **`config.js`**. Change the name, story, messages, question, photos, and notification settings there. You don't need to touch HTML or JavaScript.

---

## Deploy in Seconds

Works with any of these platforms:

**GitHub Pages · Netlify · Vercel · Cloudflare Pages**

All free. All take under two minutes.

---

## Email Notifications

Notifications are optional. If you enable them, make sure the email in `config.js` is **your own email address**. Never leave someone else's email configured in your fork.
